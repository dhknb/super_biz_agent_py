# AIOps 首响系统 · 学习教材

> 这是一套「从零看懂」的教材，讲解两周冲刺里写的每一块代码。
> 假设你**没接触过**这些代码，蕾姆会从「这天要解决什么问题」开始，
> 一路讲到「该看哪个文件、每段代码在做什么、背后是什么概念」。

## 怎么用这套教材

1. **按顺序读**：Day1 → Day10，每天的东西都建立在前一天之上。
2. **对照代码读**：每篇都标了「该看的文件」，打开它边读边对照。
3. **概念不懂就查**：遇到陌生词（Pydantic / ORM / 依赖注入…），看 [00-概念速查.md](00-概念速查.md)。

## 这个系统到底是什么

一句话：**告警来了，系统自动查知识库、生成一份带证据的排查报告。**

```
一条告警（比如"CPU 90%"）
   │
   ▼  归一化成统一格式          ← Day2
   │
   ▼  存进数据库变成"任务"       ← Day3
   │
   ▼  拿告警去知识库搜 SOP 文档   ← Day5
   │
   ▼  把告警+SOP 交给大模型      ← Day4/5
   │
   ▼  生成结构化报告（可降级）    ← Day4
   │
   ▼  区分"事实"和"推断"        ← Day5
   │
   ▼  通过 API / SSE 返回        ← Day6/9
```

每一步蕾姆都会详细讲。开始吧，昴君～
